# C4 Launcher — релизы

APK-файлы и метаданные версий приложения **C4 Launcher** (приборная панель и лаунчер
для головного устройства Citroën C4 первого поколения).

**Страница для установки: https://fakt37.github.io/can-bus-c4-releases/**
— её можно давать пользователям, она всегда ведёт на свежий релиз.

Исходный код приложения — в репозитории `can_bus_c4` (приватный).

## Как обновляются пользователи

Приложение читает `version.json` из этого репозитория и сравнивает версию
с установленной (semver). Если новее — предлагает скачать и установить.

Файл обновляется автоматически: релиз собирает GitHub Actions в `can_bus_c4`
по пушу тега `v*`, он же публикует сюда APK и переписывает `version.json`.
Руками ничего править не нужно.

## Формат version.json

```json
{
  "version": "2.1.0",
  "url": "https://github.com/Fakt37/can-bus-c4-releases/releases/download/v2.1.0/c4-launcher-2.1.0.apk",
  "notes": "Версия 2.1.0"
}
```

Имя файла APK — `c4-launcher-<version>.apk`. До версии 2.1.0 использовалось
`can-bus-c4-<version>.apk`: имя осталось от времён, когда приложение было
монитором CAN-шины, а не лаунчером. Ссылку на APK установленные копии берут
из `version.json`, поэтому смена имени ничего не сломала.
