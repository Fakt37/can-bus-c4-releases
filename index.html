Что это

Заменяет штатный экран магнитолы: показывает данные с CAN-шины автомобиля — расход, запас хода, температуру двигателя, напряжение, состояние дверей и света, ошибки бортового компьютера, климат.

Плюс лаунчер приложений, медиаплеер, камера заднего вида, назначение действий на кнопки руля и учёт технического обслуживания.

Что нужно

Магнитола
Topway TS10S (и родственные TS10, TS18), Android 9 и новее
Плата
Модуль ESP32 с прошивкой — читает CAN-шину автомобиля
Автомобиль
Citroën C4 первого поколения (2004–2010)

Без платы приложение работает как лаунчер, но данные автомобиля показывать не будет — их читает именно она.

Установка

  1. Скачайте APK — на телефон, флешку или сразу в магнитолу, если на ней есть браузер.
  2. Перенесите файл в магнитолу, если качали не на неё: подойдёт USB-флешка.
  3. Откройте файл через файловый менеджер магнитолы. Android спросит разрешение на установку из неизвестных источников — разрешите его для файлового менеджера.
  4. Назначьте приложение домашним экраном, если хотите, чтобы оно запускалось при включении: Настройки → Приложения → Приложения по умолчанию → Главный экран.
  5. Выдайте доступы — при первом запуске приложение покажет мастер и объяснит, зачем нужен каждый из них.

Первый запуск с платой

Плата привязывается к автомобилю сама: заведите двигатель и подождите несколько секунд — она запомнит VIN и дальше будет работать только на этой машине.

До привязки приложение честно скажет об этом на экране. Ничего нажимать не нужно.

Обновления

Приложение проверяет обновления само: Настройки → Обновление. Скачивание и установка — в один тап, скачивать APK отсюда повторно не нужно.
